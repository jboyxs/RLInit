# 纯 SAC 机械臂开门训练总结

日期：2026-10-19

## 1. 目标与最终结果

目标是让策略网络通过 SAC 训练，学会接近门把手、正确抓握、压下把手和拉门，并直接输出七个机械臂关节增量和一个夹爪动作。

最终冻结的模型在当前仿真场景、原始带噪声 home 初始分布下，取得以下独立评估结果：

| 指标 | 结果 |
| --- | --- |
| 完整开门 | **97/100** |
| 回合内成功抓握 | 100/100 |
| 回合内成功压下把手 | 100/100 |
| 失败原因 | 3 次触发原版穿透限制 |
| 评估种子 | 70000–70019、71000–71079 |
| 推理方式 | 确定性策略，无额外探索噪声 |

这些种子没有参与训练或最佳检查点选择。先评估 20 回合，成功 19 次；保持模型不变，再通过正式评估入口测试另外 80 回合，成功 78 次。

训练和推理没有使用模仿学习、专家动作、雅可比映射、逆运动学或新增的位姿控制器。保留了原版关节动作映射、MuJoCo 执行器和物理失败检查。

成功条件也保留原版：双侧抓住把手，门角度达到 **0.30 rad**，并持续保持 **0.30 秒**，期间没有触发物理失败。穿透失败阈值仍为 **0.005 m**。

## 2. 之前为什么一直训练不好

### 2.1 靠近把手不等于能够正确抓握

前期策略可以靠近把手，但仍会偏斜、过早闭合或只有单侧接触。只看夹爪中心到目标的距离，难以区分这些状态。

因此，精细任务把观测从 64 维扩展到 78 维，增加两侧指垫相对于把手表面的误差、居中误差、指垫间距、闭合准备度和双侧接触程度。几何信息进入观测和奖励，由网络学习对应动作。

奖励同时考虑两侧表面距离之和、两侧距离不平衡、居中和姿态对齐。未准备好时提前闭合会受到惩罚，居中且对齐后闭合可以获得奖励，双侧接触和后续动作按抓握质量加权。

这些设计的目的是让“接近、对齐、闭合并形成双侧接触”都有可学习的信号。它们是整个训练的基础，但没有单项消融实验能证明每一项分别贡献了多少。

### 2.2 学会压把手后，仍然容易在拉门时失稳

后期瓶颈转移到了保持抓握和协调拉门：

- 有些轨迹已经把门拉过目标角度，但随后脱手，未满足持续保持条件。
- 关节目标与实际关节位置的偏差会明显增大，部分回合发生穿透或碰撞。
- 训练中随机探索偶尔能产生成功回合，但固定策略的独立评估仍可能失败。

所以，训练日志中出现成功回合、抓握率提高或回报提高，都不足以证明已经学会完整开门。

### 2.3 完整开门需要多步动作配合

从接近、闭合到压把手、拉门，成功奖励需要经过较长的动作序列才能获得。单步回报依靠逐步自举传播这些奖励，早期又缺少完整成功经验，后续动作的学习较困难。

这是对现象和算法机制的解释；本次没有通过严格消融实验，单独确认它在所有失败原因中的占比。

## 3. 最终奏效的训练过程

### 3.1 保留已经学会的能力和自身经验

先通过纯在线 SAC 学到接近、抓握和压把手，之后从约 42 万步的已有网络继续训练，并加载同任务下自己采集的在线经验。

这些经验仍是普通 SAC 的状态、动作、奖励和下一状态，没有被当作动作标签进行监督拟合，也没有行为克隆损失。

最终模型不是从零训练 14 万步得到的。**14 万步只表示后续多步回报阶段所选检查点的计数，之前已经进行过训练和采样。**

### 3.2 使用三步回报，提高对后续结果的重视

与前面的主实验相比，成功实验采用以下组合：

| 配置 | 前面主实验 | 成功实验 | 调整目的 |
| --- | --- | --- | --- |
| 回报步数 `n_steps` | 1 | **3** | 让后续成功或失败的奖励更快影响较早的动作 |
| 折扣因子 `gamma` | 0.99 | **0.995** | 提高较远期收益的权重 |
| 夹爪探索噪声标准差 | 0.8 | **0.3** | 减少探索对持续抓握的干扰 |
| 网络初始化 | 已有接近和抓握能力 | 继承已有网络 | 保留已学会的动作能力 |
| 经验来源 | 自身在线采样 | 继续使用同任务自身经验 | 保留已有经验的学习价值 |

三步回报使用已安装 Stable-Baselines3 自带的 `NStepReplayBuffer`。原始经验中的动作和奖励保持不变，由库在采样时计算多步回报，并处理终止、超时、环形覆盖和最新未结束轨迹的边界。

Actor/Critic 更新继续使用标准 SB3 SAC 实现。成功模型使用均匀经验回放。

**本次同时调整了回报步数、折扣因子和探索噪声，因此能确认这套组合有效，不能把全部提升归因于某一个参数。**

### 3.3 选择最佳检查点，避免后续退化

多步回报阶段的部分固定种子评估结果如下。每次评估均从原始 home 开始，每组 5 回合。

| 该阶段训练步数 | 完整开门成功率 |
| --- | --- |
| 70000 | 1/5 |
| 110000 | 1/5 |
| 120000 | 1/5 |
| **140000** | **5/5** |
| 190000 | 4/5 |
| 200000 | 5/5 |
| 210000 | 4/5 |
| 250000 | 0/5 |

评估回调首先按完整任务成功率选模，再比较后续任务指标。最终交付的是 **140000 步的固定模型**，不是最后训练出的模型。后期出现退化，说明继续训练并不保证性能持续提高。

冻结模型后才进行前述 100 个新种子的独立测试，取得 97/100 的结果。

## 4. 尝试过但没有作为最终方案的方法

| 实验 | 观察结果 | 是否用于最终成功模型 |
| --- | --- | --- |
| 原单步回报主实验 | 能抓握、压把手；固定周期评估未完成开门 | 其已有网络和自身经验作为后续训练基础 |
| 成功回合重采样，比例 25% | 曾出现 1/5 的完整评估成功，未形成稳定成功 | 否 |
| `safe_opening` 软惩罚 | 提前惩罚目标积压、穿透和过度按压；曾出现 1/5 成功 | 否 |
| 自身中间状态课程 | 中途起步能够开门，但未稳定迁移到原始 home 完整任务 | 否 |
| 只降低动作步幅 | 连续抓握可延长，但拉门进展不足；诊断中均未完整成功 | 否 |

其中，降低动作步幅的诊断没有更新网络。最小步幅下连续抓握约 3 秒，但门只打开约 1.3°，说明只放慢动作不足以完成任务。

历史使用雅可比位姿控制器得到的 39/40 结果不符合本次“策略直接学习关节动作”的要求，已经撤回，不计入本次成果。

## 5. 成功模型的主要配置

| 参数 | 值 |
| --- | --- |
| 算法 | Stable-Baselines3 SAC |
| 网络 | 两层 256 单元、ReLU |
| 观测 / 动作维度 | 78 / 8 |
| 奖励配置 | `joint`，额外姿态误差成本 0.5 |
| 接触力观测 | `log(1 + F / 20)` |
| `n_steps` / `gamma` | 3 / 0.995 |
| 学习率 / 固定熵系数 | 0.0001 / 0.005 |
| Batch / 经验池容量 | 256 / 300000 |
| 并行环境数 | 4 |
| 更新比例 | 每条采样转移对应一次梯度更新，`gradient_steps=-1` |
| `action_scale` | 0.01 |
| 初始噪声 / 回合上限 | 0.02 / 1000 步 |
| 训练夹爪 OU 探索噪声标准差 | 0.3 |
| 中途状态重置 / 成功回合重采样 | 均关闭 |

精细任务奖励参数集中在 `GraspTrainingConfig`；成功模型具体系数以保存的配置为准。它与普通 `door_direct_env.py` 默认奖励是两种独立配置，调整其中一处不会自动改变另一种配置或已经保存的模型。

## 7. 模型、记录与使用命令

固定交付目录：`runs/door_sac_joint_v2_verified/`。

| 文件 | 内容 |
| --- | --- |
| `sac_door.zip` | 应用于观看和复现评估的固定模型 |
| `evaluation.json` | 100 回合汇总与逐回合结果 |
| `evaluation_20.json` | 第一批 20 回合的原始诊断报告 |
| `evaluation_cli_80.json` | 第二批 80 回合的正式入口评估输出 |
| `selection.json` | 140000 步检查点的选模记录 |
| `source_run_config.json` | 来源实验的训练配置 |
| `manifest.json` | 模型和源码哈希、训练来源及验证信息 |
| `opening.gif`、`video_metrics.json` | 真实策略开门录像及对应成功判定 |
| `completion_audit.json` | 目标要求与完成证据的核查记录 |

`source_run_config.json` 复制自训练运行初期，其中 `actual_timesteps=0` 是当时的配置快照值，不表示模型未训练。选中检查点的步数以 `selection.json` 和模型内保存的 `num_timesteps=140000` 为准。

在项目根目录执行以下命令，观看已验证的开门回合：

```powershell
uv run --no-sync python tests/trainp2_sac_direct.py --evaluate runs/door_sac_joint_v2_verified/sac_door.zip --model models/door_scene.xml --episodes 1 --seed 70000 --device cpu --render
```

复现两批独立评估：

```powershell
uv run --no-sync python tests/trainp2_sac_direct.py --evaluate runs/door_sac_joint_v2_verified/sac_door.zip --model models/door_scene.xml --episodes 20 --seed 70000 --device cpu

uv run --no-sync python tests/trainp2_sac_direct.py --evaluate runs/door_sac_joint_v2_verified/sac_door.zip --model models/door_scene.xml --episodes 80 --seed 71000 --device cpu
```

评估不需要训练经验池或状态库。重新运行成功实验阶段的完整训练命令见项目 `README.md`，需要本地保留的自身在线初始化权重与经验文件。`runs/door_sac_joint_v2_verified/` 内的固定模型及验证材料随代码发布；`runs/` 下其余原始训练输出、初始化材料和大经验池按项目 Git 规则保留在本地。

## 8. 结论与适用范围

此次达到目标的路径是：补足抓握观测和奖励信号，保留已经学会的能力与自身经验，再使用三步回报、更大的折扣因子和较小的夹爪探索噪声，配合独立评估选择最佳模型。

97% 是当前仿真场景和原始初始噪声分布下，固定模型在这 100 个新种子上的实测结果。仍有 3 次穿透失败，也尚未验证不同门位置、把手形状或真实机械臂上的表现。
